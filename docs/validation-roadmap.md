# Validation Roadmap

The project can progressively move from geometry generation toward experimentally validated propulsion research.

## Phase 1 — Geometry

- [x] Parametric centreline
- [x] Airfoil sections
- [x] Chord interpolation
- [x] Attack-angle interpolation
- [x] Multi-blade generation
- [x] CW/CCW generation

## Phase 2 — Geometry quality

- [ ] Self-intersection checks
- [ ] Minimum thickness checks
- [ ] Root transition checks
- [ ] Mesh watertightness checks
- [ ] Automated STL inspection

## Phase 3 — Simulation

- [ ] CFD mesh generation
- [ ] Static thrust prediction
- [ ] Torque prediction
- [ ] Pressure-field comparison
- [ ] Conventional propeller baseline

## Phase 4 — Structural

- [ ] Centrifugal loading
- [ ] Static structural analysis
- [ ] Modal analysis
- [ ] Fatigue assessment

## Phase 5 — Experimental

- [ ] Dynamometer/test stand
- [ ] RPM measurement
- [ ] Electrical power measurement
- [ ] Thrust measurement
- [ ] Torque measurement
- [ ] Acoustic measurements

The purpose of this roadmap is to distinguish geometric novelty from experimentally demonstrated performance.
